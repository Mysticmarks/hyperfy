# Troubleshooting Index

This index links incident retrospectives and quick reference guides for common
Hyperfy operational issues. Each entry references the relevant OKR IDs so
follow-up work can be tracked in quarterly reviews.

## Guides

- [LiveKit Realtime Failures](./livekit.md)
- [Database Connectivity & Persistence](./database.md)
- [CDN and Asset Delivery](./cdn.md)

## Usage

1. During an incident, update the relevant guide with timelines, root cause,
   and remediation notes.
2. Cross-link the corresponding runbook in `../runbooks/`.
3. Add links to GitHub issues (`OPS-*`, `MMO-*`) that carry the long-term fix.
4. Review and refresh this index during ops readiness checks each release.
